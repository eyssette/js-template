# Dossier `lib` de l'application

Dans ce dossier, vous trouverez les fichiers générés par le plugin [paraglide](https://github.com/inlang/paraglide-js) qui permet de gérer l'internationalisation (i18n) de l'application.

Vous pouvez aussi ajouter les librairies JavaScript externes que vous souhaitez utiliser dans votre application et qui ne peuvent pas être installées au moment de la compilation (par exemple si vous créer un système de plugins pour votre application).
